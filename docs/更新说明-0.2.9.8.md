# 0.2.9.8 · 连续使用与操作便利性

本次完成六项优化，作者署名为 **Waffing**，悬浮窗同步显示。沿用原脚本名称、namespace、模型存储键和依赖，上游版权和 MIT 授权继续保留。0.2.9.7 保留在回退目录。

1. **长时间使用**：新站点日志保留最近 300 条；答题历史每页显示 100 条，默认跟随最新，保留历史与提交防重信息。图片数据在请求处理结束后释放，离开题框时断开旧 DOM 引用。
2. **减少重复解析**：复用未变化的题干和选项结构；监听题框文本、图片、节点变化，并核对题目身份及输入值。点击与提交仍实时检查验证码、开关、当前题和选中状态。
3. **页面与请求协调**：相同来源的标签页只保留一个运行页面，支持手动接管。自动查询、模型列表、测试连接共用限速和冷却信息。接管会取消旧页待处理操作；以题目摘要保存最小提交记录，防止页面接管和刷新后重发。
4. **可操作的异常提示**：模型问题提供打开配置的入口；适用的播放受阻提示提供播放入口；诊断可复制最近 20 条脱敏日志，不含配置密钥、URL 查询参数和页面标识查询串。
5. **迷你控制条**：最小化后保留状态、倍速和暂停／恢复／接管按钮，支持展开；沿用拖动、主题和屏幕边界修正。
6. **设置备份**：导出 JSON 采用字段白名单；导入前展示变化，确认后保持暂停，保留当前 Key，拒绝带凭据的地址与跨服务商密钥复用。

另补充两项响应优化：

- 题框、文字节点、选项可用状态与图片变化立即唤醒检查，以合并的微任务调度减少定时器等待，保留每秒兜底与操作前核对。
- 自动答案查询默认 15 秒超时，取消旧请求后切到已配置的备用模型，最多尝试两次。没有备用时仅重试原模型一次；两次失败停止。等待阈值可调 5–120 秒，备用凭据独立保存，旧请求的迟到答案不能填选或提交。

新增公开更新地址与配图新手教程。网站原生进度和提交回执继续作为操作依据；已有提交结果不明确时不自动补发。

多标签页协调使用本网站来源的 localStorage，存储内容为协调标识、限速时间和题目摘要提交记录。不同来源、浏览器配置文件、脚本管理器或设备不属于同一个协调范围。遇到旧的运行标识，可以手动接管。
