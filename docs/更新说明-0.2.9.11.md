# 0.2.9.11：AI随堂练习与连续视频流程

针对 `wisdom-mooc.zhihuishu.com/study/index` 的视频中途“AI随堂练习”，替换 0.2.9.10 的简单学习页适配。保留原脚本名称、namespace、模型配置和存储键。

## 已实现

- 识别 `.ai-class-exercise-dialog`，读取题干、选项与 `[多选题]` 等类型；支持没有原生 checkbox 的多选题，以及单选、判断题。
- 复用已配置模型和超时备用模型。模型答案必须唯一匹配当前完整选项，逐项核对选中状态后才进入提交阶段。
- 点击“提交作答”后等待网站自身的成功回执；回执未知、网站拒绝、题框被移除但未收到回执时停止，避免重发。
- 网站已接受答案后，等待题框关闭；如果出现明确的“继续学习／继续播放／返回视频”按钮，点击一次后续播。
- 视频自然结束后，等待网站确认保存学习记录，再点击原播放器下一节；同一视频源只切换一次。网站复用 video 元素加载新视频源时，重新开始播放和完成检测。
- 自动播放被浏览器阻止时提示手动播放，不持续轰炸 `play()`。课程末尾、下一节不可用、缓冲和网站验证均显示状态。
- 接入暂停／恢复、手动重试、请求间隔、冷却、单标签页运行、缓存上限和页面卸载清理。
- 智慧树学习页保留网站当前倍速；跳过旧版对全局 `Function.prototype.call`、定时器的改写。其他平台原有逻辑与默认图片域名规则保持原样。

## 使用

1. 在原暴力猴／油猴脚本条目检查更新至 `0.2.9.11`，或从仓库 README 的完整脚本入口更新原条目。
2. 刷新已登录的智慧树课程视频页。保留一份启用的脚本，在“答题”中配置自己的模型接口、Key 和模型。
3. 在“设置 → 视频与AI随堂练习”确认启用助手、自动续播、自动答题、核对后提交和自动下一视频。自动播放被阻止时手动点击一次网站播放按钮。
4. 模型失败时先检查配置，再点击“重试当前题”。提交结果不明时先检查网站结果，不会自动重复提交。

## 边界

工具浏览器访问用户课程地址时跳转到登录中心，未复用外部 Edge 登录状态。本次没有在用户真实登录课堂完成视频播放、实际模型答案或网站回执验收；选择器和回执接口来自仓库历史实现，仍可能随网站版本变化。

不会伪造观看时长、心跳或学习记录，也不保证脚本不可被检测。验证码、人脸、身份验证和重新登录需要用户处理。模型正确率由题目与所用模型决定，不硬编码截图题目的答案。
