# 0.2.9.10：智慧树学习页适配（待真实页面验收）

本次新增 `wisdom-mooc.zhihuishu.com/study/index` 的学习页入口，复用原有模型配置与答题接口。超星、北部湾及智慧树旧考试页逻辑保持原样。

## 变更

- 动态扫描页面及同源 iframe 中的视频，尝试播放；自动播放被浏览器阻止时提示手动播放一次。
- 检测可见的视频弹题，解析题目、请求模型、填选并核对；无答案、解析失败、选项不唯一或填选失败时不自动提交。
- 同一弹题并发请求互斥，已点击提交的同一题面不重复提交；页面变化或题框移除后丢弃旧答案。
- 已选选项不会重复点击反选；完整保留题干，不再截断为 200 字。
- 视频结束后按“是否自动切换”设置尝试点击下一章节，保留网站和用户当前倍速。进度是否记入以网站记录为准。
- 页面离开后清理监听器和定时器。
- 源码保存为 `src/zhs-study.js` 并接入构建，避免后续构建覆盖适配。
- 版本及更新清单同步为 `0.2.9.10`，沿用原脚本名称、namespace 和配置存储键。

## 本地验证

```sh
node src/build-adaptation.cjs
node --check course-helper.user.js
node --test tests/core.test.cjs tests/zhs-study.test.cjs
```

构建与语法检查通过；原有 10 项核心测试和新增 11 项智慧树回归测试全部通过。新增用例使用模拟 DOM、模拟模型响应，不调用真实课程或模型服务。

## 验证范围与限制

未连接用户已登录的 Edge 页面，未在真实智慧树课堂完成播放、弹题、提交回执或切课验收。当前 CSS 选择器仍来自兼容性假设，网站更新可能导致无法识别。测试通过不代表真实站点已适配成功，也不保证模型答案正确。

本版没有新增绕过反调试、验证码、身份验证或学习记录校验的逻辑。题框无法识别时保留页面，由用户手动处理。没有从浏览器提取登录信息、API Key 或账户数据。

仓库原有 `artifacts/网课小助手-0.2.9.9.zip`、截图和旧验证报告仍是历史版本，不包含本次适配。请从 README 的主分支安装入口更新原脚本条目，或在脚本管理器中检查更新。
