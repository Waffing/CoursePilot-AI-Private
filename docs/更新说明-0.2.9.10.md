# 0.2.9.10 · 智慧树新版课程适配

- 新增智慧慕课视频、随堂题、知识练习，以及独立作业考试系统的可读选择题流程。
- 视频使用原播放器，倍速只选不超过 1.8× 的原生档位；自然结束且网站确认保存后才切下一视频。
- 随堂题选项核对后提交一次；考试逐题等待原生保存，整卷完成后才进入交卷确认。保存失败、结果未知或出现验证时停止。
- 沿用快速题框识别、15 秒模型超时、备用接口、文字缓存、暂停恢复、多标签页接管和个性化面板；新增独立智慧树开关。
- 更新 GitHub 安装入口和自动更新元数据，保留 0.2.9.9 回退版。

使用和限制详见 [智慧树使用说明](智慧树使用说明.md)。本轮验证基于公开资源及本地模拟页面，真实登录网站流程仍需单独验收。
