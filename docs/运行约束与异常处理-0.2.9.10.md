# 运行约束与异常处理 · 0.2.9.10

本版通过状态核对、请求间隔和失败停止减少无效操作，不伪造进度、提交回执、浏览器身份或验证码结果，不承诺网站永远不会判断异常。

## 请求与操作

- 请求最小间隔默认 5 秒，可调 2–120 秒；针对本助手的模型、搜索、图片、获取模型和连接测试。网站原生接口、外部框架资源不由该队列控制，旧公告接口已移除。
- 429、5xx、超时和网络错误触发 15 / 30 / 60 / 120 / 240 / 300 秒冷却，服务端给出更长 Retry-After 时继续等待。冷却结束不自动补发失败题，需要手动重试。
- 401、403、无效配置与无法匹配的答案保留人工处理入口。切换题目、暂停、验证出现或失去标签页运行权后，迟到的模型答案不能继续点击或提交。
- 自动答案查询默认每次最多等待 15 秒，可调 5–120 秒；超时取消旧请求并尝试一个备用模型，最多两次。没有备用则仅重试原模型一次。请求排队与冷却不占用尚未发出的模型调用预算。手动连接测试沿用原超时（10–300 秒）。图片最多 6 张、每张不超过 5 MB，PNG / JPEG / GIF / WebP；只读取允许的站点资源域名，图片题不缓存答案。
- 视频弹题在选中状态通过核对后立即提交；练习与试卷使用操作等待时间。自然播放结束且网站成功确认课程保存后切课。
- 视频缓冲超过 30 秒显示网络提示；提交或完成回执超过 15 秒显示尚未确认。已经发出但结果未知的操作不自动补发。

## 标签页协调

同一网站来源和浏览器配置文件使用一份运行权标记。新打开的页面等待，手动点击“在此页接管”后才能自动操作；接管前留出短暂的协调窗口，旧页面停止操作并暂停视频。页面关闭或缓存挂起时释放运行权，恢复时重新获取。

不同浏览器、无痕窗口、端口、脚本管理器或设备不在同一可靠协调范围。请只启用一个管理器内的一份脚本。浏览器强制退出留下的运行标记可手动接管；无法访问网站 localStorage 时不会继续自动操作。

原生提交前保存题目身份摘要和状态；新页面查到已有记录时只核对网站结果，不再次调用模型或重发同一提交。记录不是网站成功回执，也不是正确答案证明。

## 数据与隐私

| 数据 | 保存位置及范围 |
| --- | --- |
| 主模型 Key、备用模型 Key、搜索 Key | 沿用脚本管理器存储键；不写入公开仓库和设置备份 |
| 界面、倍速、请求参数 | 原有脚本配置，按管理器条目保存 |
| 文字题答案缓存 | 页面内存，最近 100 条，刷新消失；模型变化、重试、答错反馈使相关缓存失效 |
| 日志与答题历史 | 页面内存；日志最多 300 条，答题每页显示 100 条；保留提交防重信息 |
| 运行权、请求节奏 | 网站来源的 localStorage，`noshuang.helper.owner.v1`、`noshuang.helper.network.v1` |
| 最小提交记录 | 网站来源的 localStorage，`noshuang.helper.receipts.v1`；题目身份摘要、提交时间与状态，不存题干、选项、答案或 Key |

本网站的页面脚本可以访问同来源 localStorage。上面的协调键只保存最小运行信息，不属于密钥存储区；清理网站数据会同时清掉这些本地标记。请先在网站核对提交结果再操作，避免手动造成重复。

“复制诊断”只选取版本、网址来源与路径、运行状态、个性化设置以及最近 20 条日志；清除已配置的密钥、Bearer 值、URL 凭据及查询串和长数字编号。它不是任意敏感文本识别器，发送前仍应检查内容。

导入备份不能导入 Key，已有 Key 时不能直接把服务商或接口域名换成不同服务。需要迁移服务时，先在模型设置里手动配置对应接口与凭据，再导入其他设置。

## 环境与验证

目标为 Windows 上近期 Chrome / Edge，兼容目标 120+，需正常登录并允许脚本管理器运行。外部 CDN、模型服务、网络缓冲、浏览器后台节流及网站更新仍影响运行速度。

本版检查使用隔离 Edge 和模拟 GM 接口，不等于真实暴力猴安装、真实模型服务和真实账号进度／成绩已通过验收。详见 [验证报告](验证报告-0.2.9.10.md)。


智慧树新适配的域名、速度限制、题型边界和真实验收状态见 [智慧树使用说明](智慧树使用说明.md)。同一来源内协调运行权，不跨不同网站来源共享运行权。
