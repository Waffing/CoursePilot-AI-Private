# 0.2.9.12：修复可见 AI 随堂练习无法识别

## 根因与依据

- **错误**：页面已显示题干、题型和选项，助手仍提示“题目未完整加载、题型或加密文字暂不支持”。
- **预期**：读取完整题目，调用用户配置的模型，填选核对后提交，并等待网站回执。
- **根因**：上一版使用 `.ques-list > .item`，要求题目是列表的直属子节点。当前官方 `AiClassExerciseDialog` 在列表内部渲染 `ElScrollbar`，其包装层位于列表和题目之间，使旧选择器找到 0 道题。旧浏览器测试没有这个包装层。
- **修复**：使用后代题根查询，保留题目边界；补充从明确题型与真实选项控件恢复题根的后备识别，不再依赖固定包装层数。
- **防止回归**：增加官方滚动容器结构、五选项截图内容、嵌套选项、隐藏模板、题型变化、加载恢复和多题边界用例。

## 本次修改

1. 兼容滚动容器、题根和选项包装层；已知结构优先，明确题型及选项关系作为后备识别。
2. 读取可见文字，排除隐藏模板、隐藏选项和选项标记；支持 `display: contents` 题根。
3. 未识别题型不再默认单选；重复选项、加密字形和未完整加载继续停止，不请求、不提交。
4. 检查多题边界和遗漏的题型标签、独立题干，防止把相邻题合并或只处理已加载的一部分；选中核对忽略隐藏的旧标记。
5. 解析失败显示题目数、成功数及具体原因；“重试当前题”可重新扫描，后续 DOM 加载完成也可自动恢复。
6. “复制诊断”增加有界结构计数和脱敏原因，白名单不含题干、选项正文、页面 HTML、Key 或账号参数。
7. 保留原脚本名称、namespace、模型配置和存储键。超星、北部湾及智慧树旧考试页未修改；原提交回执、续播、进度保存后切课流程继续保留。
