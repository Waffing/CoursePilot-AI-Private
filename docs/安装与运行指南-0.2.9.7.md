# 网课小助手 0.2.9.7：安装与运行指南

本版优化连续切课与新视频启动，保留 7 项个性化设置、请求间隔与失败冷却。视频习题仍在核对选项后立即提交。完整脚本为 `course-helper.user.js`。安装确认和已登录网站上的验收另行记录，不将本地测试当成安装成功。

## 运行环境

- Windows 桌面，Chrome 120+ 或 Edge 120+，正常联网并登录网站；推荐使用仍获安全更新的浏览器版本。
- Tampermonkey（油猴），允许其在目标网站运行，并保留脚本声明的 GM 存储、跨域请求和依赖加载权限。
- 目标新增站点：`http://bbgu.jcedutec.cn:8932`。新版个性化窗口与自动请求节奏仅在此域名启用；原超星、智慧树处理逻辑继续保留。
- 需要能访问脚本原有的 baomitu.com 依赖 CDN，以及你自行配置的模型服务。图片题需要支持图片的模型。外部依赖未改版，也未打包为离线运行环境。
- 最低版本是兼容目标；本轮实测浏览器版本、检查数量和实站限制见 `验证报告-0.2.9.7.md`。本轮没有逐个实测 Chrome/Edge 120 到当前版本。

Tampermonkey 5.3+ 在 Chromium 浏览器上需要执行用户脚本的额外开关。Chrome 138+ 可在扩展详情启用“允许用户脚本”；其他 Chrome/Edge 版本按扩展说明检查开发者模式。这一步若尚未启用，需要你自行在浏览器扩展设置中操作。来源：[Tampermonkey 官方 Q209](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。

## 安装或更新

### 已有旧版：优先在原条目更新

1. 在油猴“管理面板”找到原来的“超星学习通｜知到智慧树--网课小助手【大模型版】”，先导出备份；交付包的 `0.2.9.6/` 也保留了上一版脚本。
2. 打开原脚本的编辑器，在文本编辑器中打开新版 `course-helper.user.js`，复制**完整内容**。
3. 在油猴原脚本编辑器中 `Ctrl+A`，粘贴新版，`Ctrl+S` 保存。原条目更新可保留该条目的模型密钥和 GM 设置；不要先删除原条目再新建。
4. 查看版本是否变成 **0.2.9.7**。保持同类助手只有一个启用条目，再刷新网页。

从私有 GitHub 仓库下载时，先登录有访问权限的账号，再下载根目录的 `course-helper.user.js`，按上述原条目编辑器步骤更新。

### 首次安装

1. 在油猴中选择“添加新脚本”。
2. `Ctrl+A` 替换模板为 `course-helper.user.js` 的完整内容，再 `Ctrl+S`。
3. 按油猴提示允许所需的站点连接，刷新网站，确认出现“网课小助手 0.2.9.7”。

若本地安装页的脚本链接被当成下载文件，使用上面的编辑器粘贴步骤即可。不要直接双击 `.js` 交给 Windows 脚本宿主运行。

## 第一次运行

1. 先打开网站的课程或考试列表，在浮窗中点击“暂停”，避免配置期间开始自动处理。
2. 切到“答题”，沿用已有模型配置，或填写服务商、接口地址、模型名和 API Key。可先点“获取模型”，再点一次“测试连接”。连接测试只验证服务返回，不代表题目答案一定正确。
3. 展开浮窗内的“个性化设置”。修改后即时生效并保存，无需重新安装。
4. 在“设置”检查自动答题、自动提交、自动下一视频等已有开关；默认行为沿用旧版。若需要自己检查答案，关闭“核对选项后自动提交”。
5. 点击“恢复”，进入课程或手动选定练习题库／正式或模拟试卷。脚本不会自行选择试卷或开始考试。
6. 遇到验证码、身份／登录验证或签名要求时，由你手动处理。请保持同一课程只有一个自动运行页面。

## 7 项个性化设置

所有项目统一保存在原配置的 `helperPreferences` 对象中。下列默认值适用于全新配置；升级时“操作等待时间”继承旧的切换、答题间隔，范围为 1–120 秒。

| 界面名称／配置键 | 默认值 | 可选范围 | 用途 |
| --- | --- | --- | --- |
| 界面主题 `theme` | 跟随系统 `system` | `system` / `light` / `dark` | 浅色、深色或实时跟随系统配色，仅影响助手 |
| 布局密度 `density` | 舒适 `comfortable` | `comfortable` / `compact` | 调整留白，紧凑模式适合小窗口 |
| 文字大小 `fontSize` | 13 px | 12–18 px | 调整窗口正文与主要控件字号 |
| 面板宽度 `panelWidth` | 360 px | 300–560 px | 设置常规宽度；答题页放宽至 1.8 倍、最多 900 px，同时受屏幕边界约束 |
| 窗口不透明度 `opacity` | 100% | 80–100% | 调整整个窗口的透明程度 |
| 请求最小间隔 `requestInterval` | 5 秒 | 2–120 秒 | 限制自动模型、搜索和题目图片请求的开始间隔；冷却时间可更长 |
| 操作等待时间 `actionDelay` | 3 秒 | 1–120 秒 | 用于题库练习、试卷和对应题目切换；视频弹题核对后立即提交，课程完成收到成功回执后直接切换 |

旧“设置 → 其他设置”的公共间隔仍保留给原平台。本网站的题库练习与试卷流程使用“个性化设置 → 操作等待时间”；视频弹题及成功回执后的切课不再额外等待。旧“启用北部湾助手”的关闭状态会迁移为“启用助手”，不会因改名自动开启。

个性化配置结构示例（仅用于说明，正常使用直接在浮窗调整）：

```json
{
  "helperPreferences": {
    "theme": "system",
    "density": "comfortable",
    "fontSize": 13,
    "panelWidth": 360,
    "opacity": 100,
    "requestInterval": 5,
    "actionDelay": 3
  }
}
```

## 浮窗与操作

- 拖动顶部标题栏移动窗口。右上角“−”最小化，旁边恢复按钮展开；这两个按钮也支持键盘聚焦后按 Enter 或空格。**最小化只收起窗口，暂停才会停助手和视频。**
- 窗口缩小、放大文字或切到答题页后，面板按实际尺寸回到屏幕范围内；内容较高时在面板内滚动。
- “暂停／恢复”控制视频和后续自动操作。“重试当前题”仅适用于查询／填选失败；冷却中或提交结果尚不明确时不会重复发请求或提交。
- “清空缓存”清理当前页面内存中的文字题答案。最多缓存 100 题，图片题不缓存；相同题干、题型和选项顺序才复用，并再次核对选中状态。模型配置变化或错题反馈也会使相关缓存失效。
- 视频倍速先读取播放器菜单；读不到时提供 1×、1.5×、2×。“自动（最高）”使用可用最高档。手选档位会保存；播放器拒绝或不支持时停止强改。

## 功能边界与异常处理

新增站点支持视频页面弹题、题库练习，以及手动开始后的正式／模拟试卷流程；保持原站的按钮、计时、选项保存和提交回执机制。每日练习及其他页面没有新增适配。当前自动识别重点是单选、多选和判断，无法唯一识别的题型会留给人工处理。

“已填选”只表示页面已选择答案；“网站已接受提交”表示收到提交成功回执，两者都不能证明答案正确。课程正常播放结束并收到网站成功回执后，助手立即点击下一视频。新视频读取元数据后就请求播放，再处理倍速；正常播放不等待倍速菜单。加载、播放状态、题框变化和回执会唤醒一次合并检查，每秒检查作为兜底；不伪造进度、不跳到片尾、不补发学习记录。

视频缓冲超过 30 秒会提示检查网络。提交／完成回执超过 15 秒仍未确认会提示人工检查，不反复提交。模型失败、请求冷却和人工验证见 `运行约束与异常处理-0.2.9.7.md`。

模型 Key 继续使用原脚本的私有存储键，公开配置副本不写入 Key；密钥不会随本交付包分发。题目文本、图片以及启用联网搜索后的题目检索内容会发送到你配置的对应服务。

## 常见问题与回退

| 现象 | 处理方法 |
| --- | --- |
| 没有浮窗 | 核对油猴是否启用、站点权限和用户脚本开关；刷新页面；检查依赖 CDN 是否可访问 |
| 提示 401／403 | 核对模型地址、模型权限和 Key；网站登录失效则手动重新登录，不循环测试 |
| 提示 429 或请求冷却 | 等待显示的冷却时间；增大请求间隔；冷却结束后检查配置并手动重试 |
| 显示“尚未确认” | 在网站核查记录或错误提示，勿在多个标签页重发 |
| 自动播放失败 | 手动点一次播放；确认没有被浏览器阻止自动播放 |
| 新播放器没有原先保存的倍速 | 在下拉框重新选择该播放器支持的档位 |
| 升级后不符合预期 | 暂停助手，在**原油猴条目**用 `0.2.9.6/course-helper.user.js` 替换内容保存，再刷新。保留安装前导出的配置备份 |
