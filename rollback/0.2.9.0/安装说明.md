# 北部湾实验室安全平台适配版 0.2.9.0

已基于你提供的 0.2.8.2 脚本增加适配。原脚本的名称和 namespace 保持一致，覆盖更新时可继续使用原来的模型配置。

## 安装

1. 在 Edge 的本地安装页点击 **安装／更新脚本**，在油猴页面选择更新或安装。
2. 如果安装页没有唤起油猴，打开油猴管理面板，找到原脚本，进入“编辑”。用本目录 `coursepilot-ai.jcedutec.user.js` 的完整内容覆盖编辑器，然后按 **Ctrl+S**。
3. 回到已经登录的课程页，按 **Ctrl+R** 刷新。悬浮面板标题应显示“北部湾实验室安全助手”。
4. 点击悬浮面板的 **答题 → 模型设置 → 连接**，检查接口地址、API Key、模型名，点击 **测试连接**。已经配置过模型的用户通常不需要重新填写。

若油猴把它识别成另一份脚本，先停用旧脚本，保持只有一份助手启用。原始版本已完整保存在 `original.0.2.8.2.user.js`，需要回退时在油猴编辑器恢复这份内容即可。

## 使用

| 页面 | 使用方式 |
| --- | --- |
| `/students/courseDetail` | 打开分配给你的课程，助手正常播放视频。出现“视频习题”后，自动调用模型，选中答案，核对控件状态，再点网站原生“提交”。提交成功后由网站继续播放。 |
| 同页左侧课程目录 | 当前视频自然结束，且收到后台的完成成功回执后，进入目录中的下一视频；从当前课程开始向后播放。 |
| `/students/practice` | 手动选择题库类型、开始和结束序号，点击开始练习。进入题框后自动作答、下一题，最后一题点击原生“提交”。 |

本次接入的是上述课程视频、视频弹题和题库练习。考试和每日练习页面不在本次适配范围内，也不会被自动启动。

默认开启自动播放、静音、自动答题、核对后提交、下一视频和题库下一题。答题后的操作间隔沿用原脚本“切换、答题间隔，单位秒”，默认 3 秒。

在 **设置 → 视频与练习设置** 中可以单独关闭这些功能。取消“启用北部湾助手”会取消尚未完成的模型请求，并停止后续自动操作。视频播放本身仍可通过播放器控制。

如果浏览器阻止自动播放，手动点击一次视频播放按钮。悬浮窗遮挡页面时，可以拖动蓝色标题栏移开。

## 题型与模型

- 支持单选、多选和判断。多选会先清除不属于当前答案的旧选项，判断题按页面上的“正确／错误”文字定位。
- 图片题会将题目和选项图片读取为图片数据，传给你配置的模型。请使用支持图片输入的模型；已接入 OpenAI Chat、OpenAI Responses、Anthropic 和 Gemini 的图片格式。
- 每题最多读取 6 张 PNG、JPEG、GIF 或 WebP 图片，每张最大 5 MB。题库中的图片主素材也会一并发送；音频、视频题目素材需要人工处理。
- 接口地址、密钥和模型名仍在原来的配置位置。新增适配没有内置模型账户或 API Key，也不会使用本聊天的模型账户代替你的接口。

模型鉴权失败、超时、答案格式不正确或选项无法唯一对应时，本题会暂停，不会随机选择或持续重复请求。修正模型配置后会重新尝试；也可以先关闭、再开启“启用北部湾助手”。

若选项在提交前被你手动改动，自动提交会停止。网站没有确认提交成功时，本题不会重复提交。验证码或登录验证需要手动完成，完成后助手继续检查页面。
